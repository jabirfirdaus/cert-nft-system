Apa itu IjazahChain?
IjazahChain adalah platform verifikasi ijazah digital berbasis teknologi blockchain Ethereum. Setiap ijazah disimpan sebagai data permanen di blockchain — tidak dapat diubah, dihapus, atau dipalsukan.
⛓️
Immutable & Terdesentralisasi
Data tersimpan di ribuan node Ethereum. Tidak ada server pusat yang bisa diretas atau dimanipulasi.
🌐
Verifikasi Terbuka
Siapapun — HRD, perusahaan, institusi — bisa memverifikasi ijazah secara langsung tanpa perlu menghubungi kampus.
📦
File di IPFS
Dokumen fisik ijazah disimpan di jaringan IPFS (Pinata), sehingga tidak terhapus selama ada yang menyimpannya.
🔐
Keamanan Kriptografi
Setiap penerbitan ditandatangani dengan private key admin menggunakan standar kriptografi Ethereum (ECDSA).
🛠️ Teknologi yang Digunakan
⬡ Solidity 0.8.20 Ξ Ethereum (Sepolia) 🐍 Python Flask 🌍 IPFS via Pinata 🔩 Web3.py 🔨 Foundry
📋 Cara Kerja
1. Admin upload file ijazah → dikirim ke IPFS (mendapat CID unik)
2. Backend membuat metadata JSON → upload juga ke IPFS
3. Smart Contract menerima data (Nama, NIM, Wallet, CID IPFS) → disimpan di blockchain
4. Siapapun bisa verifikasi dengan memasukkan NIM → data ditampilkan langsung dari blockchain
