Kenapa blockchain untuk ijazah?

Ijazah kertas bisa dipalsukan dan database kampus bisa diretas. Blockchain menyelesaikan ini secara fundamental — data tidak disimpan di satu server, melainkan tersebar di ribuan node di seluruh dunia. Tidak ada satu pihak pun yang bisa mengubahnya setelah data masuk.

Cara kerjanya

1
File ijazah diunggah ke IPFS. Pinata IPFS menyimpan file dan menghasilkan CID — hash unik yang menjadi identitas permanen file tersebut.
2
Metadata JSON dibuat dan diunggah. Sistem membuat file JSON berisi nama, NIM, institusi, dan URL file, lalu mengunggahnya ke IPFS juga.
3
Smart contract mencatat URI metadata. Backend menandatangani transaksi dan mengirimnya ke Ethereum. NIM menjadi kunci unik permanen yang terikat ke URI metadata.
4
Verifikasi terbuka tanpa perantara. Masukkan NIM di tab Verifikasi. Sistem membaca blockchain langsung, mengambil metadata dari IPFS, dan menampilkan hasilnya.
