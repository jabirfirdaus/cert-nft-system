Kenapa Blockchain?

Ijazah kertas bisa dipalsukan dan database kampus bisa diretas. Blockchain menyelesaikan ini secara fundamental — data tersebar di ribuan node, tidak ada satu pihak pun yang bisa mengubahnya setelah data masuk ke chain.

Cara Kerjanya
1
File diunggah ke IPFS — Pinata menghasilkan CID unik untuk file ijazah.
2
Metadata JSON dibuat — berisi nama, NIM, institusi, dan URL dokumen.
3
Smart contract mencatat URI — NIM jadi kunci permanen di Ethereum.
4
Verifikasi terbuka — siapapun bisa cek tanpa perantara.
