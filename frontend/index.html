Kenapa blockchain?

Ijazah kertas bisa dipalsukan, diedit, bahkan dicetak ulang. Database kampus bisa diretas atau rusak. Blockchain menyelesaikan ini dengan cara yang berbeda — data tidak disimpan di satu server, tapi tersebar di ribuan node di seluruh dunia. Tidak ada satu pihak pun yang bisa mengubahnya setelah data masuk.

Cara kerjanya

1
Admin upload file ijazah. File dikirim ke IPFS via Pinata — jaringan penyimpanan terdesentralisasi yang menghasilkan hash unik (CID) untuk setiap file.
2
Metadata dibuat dan diupload. Sistem membuat file JSON berisi nama, NIM, universitas, dan link ke file ijazah, lalu menguploadnya ke IPFS.
3
Smart contract mencatat data. Backend menandatangani transaksi dengan private key admin dan mengirimnya ke kontrak Ethereum. NIM menjadi kunci unik permanen.
4
Siapapun bisa memverifikasi. Masukkan NIM di tab Verifikasi. Sistem membaca langsung dari blockchain — tanpa server perantara, tanpa bisa dimanipulasi.
